Why use an Artificial Neural Network for intrusion detection?

Every chart on this page is drawn from the evaluation saved by the notebook (held-out test set). Nothing here is typed in by hand, and the honest trade-offs are included.

It learns combinations

One feature alone rarely gives an attack away. A neural network's hidden layers learn combinations such as "tiny reply + unusual TCP flags + rare port", which a straight-line model cannot express.

It outputs a probability

The sigmoid output is a number between 0 and 1. A security team can move the threshold to trade missed attacks against false alarms, without retraining.

It can be told attacks matter more

Attacks are rare. Class weights make a missed attack cost more in the loss, which pushes the network towards detecting them instead of ignoring them.

12. The honest limits
  • The model is binary: it says attack or normal, not which attack type.
  • It was trained on flows from one dataset (NF-UNSW-NB15) using these ten features; other networks may behave differently.
  • It cannot recognise an attack type that looks nothing like the training data.
  • This app scores uploaded flow records. It does not capture live packets or block traffic.
  • At the default threshold the ANN raises more false alarms than the Random Forest; the threshold slider shows the trade-off.
